# SF Pro Display fonts

To use SF Pro app-wide, add these font files to this directory:

- `SF-Pro-Display-Regular.otf`
- `SF-Pro-Display-Medium.otf`
- `SF-Pro-Display-Semibold.otf`
- `SF-Pro-Display-Bold.otf`

**Source:** Download from [Apple Developer – Fonts](https://developer.apple.com/fonts/) (SF Pro Display), or from the [apple-san-francisco-pro-fonts](https://github.com/chris-short/apple-san-francisco-pro-fonts) repository. Ensure your use complies with Apple’s license.
